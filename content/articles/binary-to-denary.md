## The idea

Computer တွေမှာ data ကို ကိုယ်စားပြုဖို့ Binary ကို အသုံးပြုပါတယ်။ Binary ဟာ **0 နဲ့ 1** ဆိုတဲ့ ဂဏန်းနှစ်လုံးကိုပဲ အသုံးပြုတဲ့ base-2 number system ပါ။

နေ့စဉ်သုံးနေတဲ့ Denary ကတော့ 0 ကနေ 9 အထိ အသုံးပြုတဲ့ base-10 number system ဖြစ်ပါတယ်။

Binary ကနေ Denary ပြောင်းဖို့ဆိုရင် ဂဏန်းတစ်လုံးချင်းစီရဲ့ **Place value (နေရာအလိုက်တန်ဖိုး)** ကို သိထားရပါမယ်။

ညာဘက်ဆုံးနေရာကနေ ဘယ်ဘက်ကို သွားတဲ့အခါ place value တွေက နှစ်ဆစီ တိုးသွားပါတယ်။

**1 → 2 → 4 → 8 → 16 → 32 → 64 → 128**

ဥပမာ `10110` ဆိုတဲ့ unsigned binary ကိန်းကို Denary ပြောင်းကြည့်ရအောင်။

| Place value | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|
| Binary digit | 1 | 0 | 1 | 1 | 0 |

**1 ဖြစ်နေတဲ့နေရာတွေရဲ့ place value ကိုပဲ ပေါင်းပါမယ်။** 0 ဖြစ်နေတဲ့နေရာတွေက စုစုပေါင်းတန်ဖိုးထဲ ဘာမှမထည့်ပေးပါဘူး။

ဒါကြောင့်

`16 + 4 + 2 = 22`

အဖြေက **10110₂ = 22₁₀** ဖြစ်ပါတယ်။

အောက်ခြေက ₂ နဲ့ ₁₀ တို့ဟာ သက်ဆိုင်ရာကိန်းကို Binary နဲ့ ရေးထားသလား၊ Denary နဲ့ ရေးထားသလားဆိုတာ ဖော်ပြတာပါ။

## Try it

**မေးခွန်း**

Unsigned binary ကိန်း `00101101` ကို Denary အဖြစ် ပြောင်းပါ။

အဖြေမကြည့်ခင် place value တွေ ချရေးပြီး ကိုယ်တိုင် စမ်းတွက်ကြည့်ပါ။

**အဖြေ**

| Place value | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|---|---|
| Binary digit | 0 | 0 | 1 | 0 | 1 | 1 | 0 | 1 |

1 ဖြစ်နေတဲ့နေရာတွေက **32, 8, 4 နဲ့ 1** ဖြစ်ပါတယ်။

`32 + 8 + 4 + 1 = 45`

ဒါကြောင့် **00101101₂ = 45₁₀** ဖြစ်ပါတယ်။

ရှေ့ဆုံးက 0 နှစ်လုံးဟာ ကိန်းရဲ့တန်ဖိုးကို မပြောင်းလဲစေပါဘူး။ `00101101` နဲ့ `101101` ဟာ unsigned binary အနေနဲ့ တန်ဖိုးတူပါတယ်။
