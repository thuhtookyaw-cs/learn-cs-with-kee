# TU01 Pann Yeat Journal font

TU01_Pann_Yeat.ttf was supplied by the website owner as the replacement Journal font on 22 October 2026. The accompanying licence is preserved in LICENSE.txt.

The Journal layout loads the unmodified font for existing and future posts. Burmese and English post titles, descriptions, and article text use the same face. Code examples retain their monospace font.
